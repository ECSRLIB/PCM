HOW TO PUBLISH THIS WEBSITE
===========================

1. Open https://github.com/ECSRLIB/pcmlibrary.github.io
2. (Optional, recommended) delete the old files in the repo first so no unused files are left:
   index.html, about.html, 1ECSR.png, ECSR.png, bg_video.mp4, and the *.xlsx files in the root.
   (Do NOT delete the .github folder.)
3. Click "Add file" -> "Upload files".
4. Open this folder in Finder, select EVERYTHING INSIDE it (Cmd+A) and drag it into the GitHub page.
   Tip: press Cmd+Shift+. in Finder to show hidden files, so .nojekyll and .github are included.
5. Write a message like "Publish new PCM Library website" and click "Commit changes".
6. Wait 1-2 minutes. The site will be live at:
   https://ecsrlib.github.io/pcmlibrary.github.io/

Check progress under the "Actions" tab of the repo (green tick = published).
If the site does not appear: Settings -> Pages -> Source = "GitHub Actions".

You can delete this file after uploading.
